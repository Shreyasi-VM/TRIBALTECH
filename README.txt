Santali Shala – offline tablet setup
1. Upload this folder to any HTTPS host (GitHub Pages / Netlify Drop) OR run on the tablet: Termux -> python -m http.server 8000 -> open http://localhost:8000 in Chrome.
2. Open once with internet, allow the microphone, then Chrome menu -> Install app / Add to Home screen.
3. After that the app opens offline: dataset translation, table, flashcards and Santali speech all work without internet.
4. Voice input offline: install the Hindi offline pack (Google app / Gboard -> Voice typing -> Offline speech recognition -> Hindi) and Hindi text-to-speech voice data (Settings -> Text-to-speech -> Google -> Install voice data). Otherwise type or tap the phrase buttons.
AI translation of sentences outside the dataset needs internet inside claude.ai and is not available in this offline copy.
